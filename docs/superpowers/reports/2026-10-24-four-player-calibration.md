# 四人桌 NPC 校准报告

配置版本 `2026-10-24.2`。种子 20261024 与 20261025。四人桌，大盲 10。1326 组合按分支权重统计，不是抽一次随机动作。

改前基线（配置 `2026-10-24.1`，见规格第 2 节）：大盲面对枪口 2.5bb 弃牌约 85.82% / 78.43% / 91.70%；人类开到 2.5bb 后对手直接全弃约 UTG 68.71%、BTN 46.12%、SB 78.07%。本文件的“旧混合”行已经使用校准后的稳健/松凶范围，只把第三个人换回保守 `ai_2`，用来看换组合的增量，不能和改前 68.71% 直接相减。

100bb 大盲面对常规开池的继续率落在规格区间。松跟的继续里跟注占七成以上，松凶的再加注比松跟至少高 5 个百分点。小盲面对按钮时，松跟的总继续低于松凶，因为松凶有大量 3bet；松跟的跟注比例仍然更高。2.5bb 和 3bb 都属常规价格，范围表不按这两个尺度再拆，所以联合全弃率相同。

固定人类 100bb 见翻牌从 9.15% / 9.30% 升到 11.15% / 11.70%。15% 的体验参考没有达到：对照策略开池偏紧，面对超过 4bb 的加注会弃牌。全桌翻牌从约 17% 升到约 27%。没有让机器人读取人类底牌或强制跟注。
