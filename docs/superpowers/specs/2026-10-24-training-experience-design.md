# 德州练习体验改进规格

日期：2026-10-24（Asia/Shanghai）

状态：评审完成，待实施。当前基线：`1887237`。

配套计划：`docs/superpowers/plans/2026-10-24-training-experience.md`。

## 1. 目标与评审结论

把已有的四人德州游戏变成能练位置、跟注价格和翻后判断的工具：对手风格可辨，行动信息可用，一手结束能解释，筹码深度可选。

用户在 $1/$2、100bb 新手桌打了 6 手，仅一手到翻牌，净亏 $20；离桌后大厅也减少 $20。这份反馈主要指出练习体验问题，现有资金结算不需要因此重做。6 手不能证明长期最优策略是任意两张偷盲，也不能代表稳定的 NPC 频率；范围代码已经提供了需要调整的独立证据。

| 当前行为 | 代码证据 | 处理 |
| --- | --- | --- |
| 盲注经常弃牌，跟注较少 | `src/ai/profiles.ts` 范围偏窄；`src/ai/preflop.ts` 命中价值 three-bet 范围后优先直接再加注 | 扩大正常价格下的防守；给中间牌配置 call/3bet 混合 |
| 激进 NPC $6 常再加到 $20 | 固定 `currentMaxBet × 3.4`，取整后得到 $20 | 按位置、开池尺度、冷跟人数定尺寸；不为增加随机感乱改金额 |
| 下一手不能回看上一手 | `src/store/gameStore.ts` 的 `startHand/leaveTable` 清空日志和行动 | 独立保存最近已完成手牌 |
| 决策信息与快捷金额不足 | `src/components/GameTable.tsx` 只显示 D、金额，所有街共用底池快捷 | 位置、bb、实际跟注价格；翻前改用 bb/加注倍数 |
| 教学区不能辅助听牌判断 | `src/components/TeachingPanel.tsx` 已有中文成牌描述，但无听牌、位置分析 | 补充可见牌分析，图鉴折叠 |
| 三个级别都是 100bb | `src/components/Lobby.tsx`、`src/App.tsx` 固定买入 | 分离盲注级别与训练场景，支持 40/100/200bb |
| 资金提示夸大风险 | 仅以 30 买入阈值显示“破产风险极高” | 显示买入倍数和建议性质，保留可编辑练习资金 |

本轮在现有 TypeScript NPC 上改进。保留上轮已完成的价格分档、禁止意外全下、真实翻后行动位置和过期决策拦截，不重做接入，不复制 texaspoker 代码。

## 2. NPC：范围与风格先可测量

### 2.1 当前基线与首版目标

以下为范围展开后的策略机会频率，不是实战 VPIP：四人桌、100bb、正常价格、完整加注合法、无已知对手牌阻挡；BTN 前面无人自愿入池，BB 面对一次正常开池。对子/同花/非同花分别按 6/4/12 个实体组合加权，范围展开去重；激进诈唬按配置的 50% 期望混合计算。

| 风格 | 当前 BTN 开池 | 当前 BB 跟注 | 当前 BB 再加注 | 当前 BB 总继续 |
| --- | ---: | ---: | ---: | ---: |
| 德州老手／稳健 | 23.68% | 8.45% | 5.73% | 14.18% |
| 激进小伙／激进 | 35.44% | 9.65% | 10.71% | 20.36% |
| 保守大叔／保守 | 9.05% | 1.66% | 2.87% | 4.52% |

现有价格护栏在 100bb 面对 2.5–3bb 开池时仍为 normal，这个体验问题不是上轮价格修复误伤。

首版训练校准目标如下，作为产品验收参数，不宣称 GTO 或收益最优。BB 目标场景固定为 UTG、SB 已弃牌，BTN 开到 2.5bb，BB 尚未自愿行动。

| 风格 | BTN 首入池开池 | BB 总继续 |
| --- | ---: | ---: |
| 稳健 | 30–40% | 35–50% |
| 激进 | 40–55% | 45–60% |
| 保守 | 18–25% | 20–35% |

最终实测参数保持激进 > 稳健 > 保守，同场景相邻风格至少相差 5 个百分点。实现后保存真实报告；若合法性或风险约束使某个目标不适用，记录反例与调整依据，不能只改测试期望掩盖偏差。

### 2.2 行为要求

- 正常价格下按开池者位置配置防守：面对 BTN 与 UTG 不能共用完全相同的继续策略。SB 开池、防守也进入报告，不要求 SB 与 BB 防守同样宽。
- 分开配置可继续范围与动作混合。强价值牌可以高频再加注；中间价值牌在 call/3bet 间混合，避免所有合格牌被直接再加注吸走。激进再加注较多，稳健跟注较多，保守总体继续范围更窄。
- 所有概率继续使用可注入 RNG，并有边界测试；概率不能绕过价格过滤、加注权限或 `shoveOk`。large/high-risk 档、便宜短码例外及无资格边池处理继续保留。
- 首入池、隔离平跟者、three-bet/four-bet 分别处理。位置与前面行动改变范围；实际筹码深度改变风险，40bb 不能直接套用 200bb 的继续许可。
- 再加注尺寸参考当前最高注、实际 IP/OOP 和冷跟人数。无位置可更大；同一场景出现相同金额正常，不把 $20 本身当作错误。不按真实牌力设置明显尺寸暗号。
- 三个名字应对应真实配置。训练场景替换对手时同步更改名称/风格说明，不能让叫“保守”的玩家套激进配置。

### 2.3 报告与分母

新增可重复运行的范围报告：枚举 1326 实体组合或等价的去重加权范围，固定场景，输出 fold/call/raise 及配置版本。不得把 169 类手牌等权计算。

场景矩阵至少覆盖 BTN/UTG 开池、BB/SB 防守、2.5bb/3bb、40/100/200bb，以及 large/high-risk 回归。首入池分母是前面无人自愿入池且轮到该位置的机会；防守分母是该位置真的面对指定开池的机会。报告中三种动作比例合计 100%。

批量对局使用相同种子和固定人类策略，分别记录全桌见翻牌率、人类见翻牌率、按机会统计的偷盲与防守、按手统计且排除盲注的 VPIP。发牌与决策使用独立随机流，每手发牌种子固定，避免策略改变 RNG 消耗后连牌序也改变；人类策略的范围、尺度和参数在前后版本保持不变，不能套用一起被调整的新 NPC 配置。先记录旧基线，再比较新版本；首版可跑 500 手。多手模拟是体验验证，不保证每几手必见翻牌，不强制 NPC 跟注，不用预设牌局制造结果。

## 3. 行动区：金额、位置和价格口径

### 3.1 本手位置与筹码

每个座位显示本手 BTN/SB/BB/UTG；本人显示 `$180 · 90bb`，行动区同时显示本人位置和筹码深度。需要显示有效筹码时明确比较对象，至少提供针对各未弃牌对手的有效筹码，不把多人局硬压成一个含糊数字。

在开局时保存本手按钮和座位角色，弃牌不会重新命名 UTG/BTN。现有 `handleShowdown.finish` 立即轮换 `dealerIndex`，因此结算后展示及回顾不能直接用它重算本手位置。区分本手按钮与下一手按钮即可，不扩展到新增人数模式。

### 3.2 跟注价格

复用合法动作/价格辅助逻辑：`toCall = max(0, currentMaxBet - currentBet)`，实际投入 `C = min(chips, toCall)`。按钮显示实际 C；短码写“全下跟注 $C”，不能显示玩家付不起的金额。可免费过牌时显示过牌，不显示无意义百分比。

普通无边池场景，P 是**轮到本人行动时、已包含对手下注的当前底池**：

- “跟注占当前池”：`C / P`。
- “摊牌权益门槛参考”：`C / (P + C)`。注明忽略后续下注、权益实现和抽水，不能等同于确定应跟注或实际胜率。

边池场景以本人跟注后可争夺的池计算，排除无资格边池及应退还的未匹配投入。多层池面对不同对手时显示各池价格/参考，或明确“多边池，仅作参考”，不得用全桌底池给出精确门槛。价格分析只用公开投入，不需要隐藏底牌。

用户第 1 手是回归样例（假定没有抽水和额外行动）：

| 时点 | 当前池/下注前池 | 本次金额 | 正确解释 |
| --- | ---: | ---: | --- |
| 翻前面对 $20，再跟 $14 前 | 当前池 $27 | 跟 $14 | 跟注占池 51.9%；门槛 34.1%；跟后池 $41 |
| 翻牌对手下注前 | 下注前池 $41 | 下注 $33 | 对手下注尺度 80.5% |
| 对手打 $33，轮到本人 | 当前池 $74 | 跟 $33 | 跟注占池 44.6%；门槛 30.8%；跟后池 $107 |

不能把下注前的 $41 当成轮到本人跟注时的当前池。实战以记录的真实状态为准，不以用户回忆的约数替代状态。

### 3.3 金额快捷与术语

- 翻前未开池：`2.5bb / 3bb / 3.5bb`，默认合理开池额；前面平跟时标明隔离加注语境。
- 翻前面对开池/再加注：按当前目标给 `3× / 3.5× / 4×` 等合法快捷，明确“加到 $X”，按位置选择默认值。
- 翻后无人下注：`⅓池 / ½池 / ¾池 / 满池`，目标为 `f × P`；面对下注时池口加注目标为 `M + f × (P + C)`，M 为当前最高注，P 已含对手下注，C 为补齐金额。先确认可完整跟注及加注，再取整并校验边界，显示目标总额和本次新增投入。
- 保留 Min、金额输入和辅助滑杆；常用额度靠快捷完成。金额统一按现有整数筹码取整，例如 $5 大盲的 2.5bb 显示“约 2.5bb · $13”。
- 统一合法边界、短码全下、未重新开放加注权限。快捷被边界夹到全下时直接标“全下 $X”；不将重复金额显示成几个不同的有效选择。
- 按动作前状态命名：本街无人下注时是“下注”，面对下注才是“加注”；实际补齐是“跟注”；全下按下注/加注/跟注分类。内部 `raise` 接口可保留，文案不必改写整个执行器。

## 4. 已完成手牌回顾

### 4.1 生命周期与数据

新增独立的已完成手牌历史 store，默认保留最近 20 手，采用带版本的本地持久化。牌桌有“本手回顾/最近手牌”，离桌后的大厅也有入口；下一手、离桌和刷新后仍能查看。加载失败、存储满或不可写时游戏继续，至少保留本次会话的内存档案。首版记录功能启用后的新手牌；旧文本日志缺失的对手底牌和状态不能补造。

本手开始创建内部记录缓冲，所有动作按执行顺序追加；在 `handleShowdown.finish` **筹码支付完毕、按钮轮换前**明确归档并深复制，使用 `sessionId + handNumber` 去重。归档直接接收 finish 中已支付的 `newPlayers`、`potLeft`、各池明细和本手原按钮快照；最终 commit 前不能从 `get().players` 读取结束筹码，那仍是支付前状态。不能订阅 `stage === 'showdown'` 就归档：当前代码会先进入该阶段再支付底池。进行中的退出不归类为已完成，也不公开底牌。

最小档案字段：

| 数据 | 内容 |
| --- | --- |
| 身份 | 版本、sessionId、handNumber、开始/结束、级别与训练场景快照 |
| 初始状态 | 本手按钮/座位角色、玩家身份和风格、盲注前筹码、真实底牌 |
| 实际牌面 | 每条街实际发出的公共牌；未发街保持空白 |
| 每个动作 | actionSeq、actorId、街、实际动作类型、当时公共牌、potBefore、currentBetBefore、currentMaxBetBefore、callCost、amountAdded、实际 raiseTo、raiseIncrement、是否全下 |
| NPC 执行依据 | 绑定本次实际动作的 turnToken、原因码、位置、价格档、抽样数、估计权益/假设；安全降级单独标注 |
| 结算 | 各层池获奖和退款、本手初末筹码与净变化、结束方式 |

每条街的首枪比例用 `amountAdded / potBefore`；加注分别展示加到总额、本次补入、加注增量，不把三者混为一谈。已有字符串日志继续展示/同步，但新回顾不能解析文本来猜金额。公共行动结构仍不能含隐藏底牌。

AI 自动重买发生在下一手开始，计入下一手起始筹码，不能算成本手盈利。当前资金余额与结算由现有游戏/资金 store 负责，回顾只读，不能重复派彩或返还买入。

### 4.2 AI 理由的绑定

现有 diagnostics 只有最近 40 项，缺少行动身份；正常策略在执行前记下意图，也可能因合法性检查而降级。不能靠诊断列表顺序或事后 Promise 回调猜本手理由。

执行器确认实际动作后、调用 store 动作前，同步传递带 turnToken/actorId 的上下文；store 将它与实际行动一起记录。最终 NPC 动作可能同步触发整手结算，归档前必须已经有这条理由。失效、重复、未执行任务不进入有效行动档案；fallback 标成“安全降级”，不包装成主动战略弃牌。

回顾将“NPC 当时的执行依据”与“通用练习提示”分开：前者来自真实原因码和参数，后者可说明位置、范围、价格。权益估计仍注明当前抽样模型的假设，不把对手真实底牌补入后重新算出的结果伪装成 NPC 当时知道的信息；不宣称玩家某次弃牌确定错误。

### 4.3 公开边界与呈现

只读已结算档案才能亮出所有对手底牌，包括已弃牌者。本人弃牌而 NPC 仍在继续时不可提前查看。实时人类提示及 NPC observation 都只使用各自底牌与公开信息。

展示顺序：本手结果/净变化 → 座位和底牌 → 按街行动、下注尺度、跟注价格 → NPC 原因与简短位置提示。全弃赢池也能回顾；没有实际发出的转牌/河牌不从 deck 补发，不伪造后续结果。

首版历史独立本地保存，不把新私有档案塞进 `src/store/logSync.ts` 实时上传队列。现有日志协议保持兼容；云端完整回顾同步另行设计。

## 5. 教学面板与日志

翻前显示具体底牌/手牌类别，例如“33，小口袋对子”“KQo，非同花高张”，并显示本人位置和当前开池/再加注语境。给通用范围提示即可，避免无依据的精确牌力分数。

翻后保留已有中文成牌描述，新增主要听牌：同花听牌、两头顺、卡顺及组合听牌。出张按可见牌去重；同花和顺子共同改善的同一张只计一次。标为“成牌出张，不保证获胜”；后门听牌单独说明，不能算作下一张即可完成的 outs。没有个人有效听牌时不把公共牌的改善包装成独占优势；河牌不显示未来听牌概率。分析模块仅接收本人底牌和已发公共牌。

图鉴默认折叠、可展开，日志获得更多高度。每手重复的花色记法移至一次性帮助入口；行动日志保留街道分组与真实金额，下注/加注文案与行动区一致。本轮补信息和结构，不做整站视觉重设计。

## 6. 训练场景、买入与资金文案

盲注级别与练习场景分为两个配置维度，避免“高额 = 深筹”的误导。现有 $1/$2、$2/$5、$10/$20 保留为单位/级别选项；主要练习场景至少提供：

| 场景 | 推荐深度 | 主要练习 |
| --- | ---: | --- |
| 标准翻后 | 100bb | 校准后的三种风格、位置、防守和跟注价格 |
| 短筹决策 | 40bb | 投入比例、低 SPR、全下与继续范围 |
| 深筹练习 | 200bb | 位置、听牌、更多街的投入；可配置偏松对手组合 |

同时允许选择 40/100/200bb 买入和至少“混合/偏松/偏紧”对手组合，界面可使用三个预设加简洁的买入/对手选择，不必加复杂配置向导。场景应改变真实 stack/profile，不能只改名称。深度是推荐值，实际有效筹码随手牌变化，不承诺整场始终维持该深度。

将盲注、scenarioId、买入 bb、解析后的整数金额、NPC 名称/profile 放入一份会话配置；可以提取为游戏配置模块，避免游戏 store 长期依赖 UI 导出的类型。入座扣款、human/NPC 初始化、补买、资金不足检查、显示和日志使用同一实际金额。改变未入座选项不扣钱；回顾保存当时配置而非读取最新选项。

资金不足仍阻止入座/补买。低于 30 买入的提示改成建议，例如：“当前练习资金约可买入 13.9 次。30 个买入是长期资金管理的常见参考，并非本次游戏的破产概率。此资金可在设置中调整。”

保留“设置练习资金”，不将模拟资金当作严格账户约束，不据此搭建真实账户风控系统。资金管理倍数按本次实际买入计算，不能继续固定引用旧 `table.buyIn`。修改配置不得覆盖已保存余额。

## 7. 验收与交付边界

1. 范围报告满足首版目标及风格排序，BB 跟注和再加注分开统计；大额价格、短码与全下许可回归继续通过。
2. 界面四个位置与本手按钮一致；金额/bb 正确；短码跟注不夸大投入；第 1 手 $27→$41→$74 示例正确；多边池不展示虚假精确门槛。
3. 翻前/翻后快捷随语境切换，整数取整、min/max、短码全下、无再加注权限均正确；动作术语一致。
4. 全弃、翻牌弃牌、多人摊牌、全下/边池都能归档；最终 NPC 理由不漏；同一手不重复；下一手/离桌/刷新不丢最近记录；尚未结束时不泄露底牌。
