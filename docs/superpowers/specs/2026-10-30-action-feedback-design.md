# 座位行动标签与短音效规格

日期：2026-10-30（Asia/Shanghai）

状态：已实现。

配套计划：`docs/superpowers/plans/2026-10-30-action-feedback.md`。

## 1. 目标

对手行动发生在座位上，不需要看侧边栏流水才能知道刚才发生了什么。四家座位（含本人）用同一套文字标签显示本街最后一次主动行动。行动发生时播放一声很短的音效。右上角可以关掉音效，选择会被记住。

侧边栏流水保持现在的内容、顺序和滚动，不改记录库，不改结算。

## 2. 不做的事

- 不做弃牌收牌、筹码飞行、粒子、震屏或筹码堆。
- 盲注不是主动行动：不写标签，不播放声音。座位旁已有的黄色本街金额继续表示盲注和后续投入。
- 没有音量滑杆。
- 不为赢牌、发牌、换街单独配声音。
- 不从 `gameLog` 文本反推行动。标签和音效只看 `streetActions`、座位状态和当前阶段。
- 不改 `PublicAction` 的字段。跟注的 `to` 仍是 `null`，标签不补金额。

## 3. 座位行动标签

### 3.1 位置

姓名和筹码下面保留庄家按钮 `D` 和黄色本街金额。去掉英文 `Folded` 和 `ALL-IN`。它们的位置改成一行中文行动标签。

这一行有固定高度。没有标签时留空，座位和牌不上下跳。四个座位共用同一个纯函数和同一段渲染，不能只改其中一家。

### 3.2 文案

只显示该座位当前应显示的一条。优先级从高到低：

1. `status === 'folded'`：`弃牌`。留到下一手开始。
2. `status === 'all-in'`：`全下`。不区分跟注全下、加注全下或不足额全下。留到下一手开始。
3. 否则取该玩家在**当前下注街**的最后一条非 `post` 行动：

| `kind` | 条件 | 文案 |
| --- | --- | --- |
| `check` |  | `过牌` |
| `call` |  | `跟注` |
| `fold` | 状态尚未变成弃牌时不应出现；若出现仍显示 | `弃牌` |
| `raise` | 翻后，且这条之前的本街行动里没有 `post`、`call`、`raise` | `下注 $N` |
| `raise` | 其余情况，包括翻前任何加注 | `加注到 $N` |

`N` 是该条 `raise` 的 `to`，并且是大于 0 的安全整数。不满足时只显示 `下注` 或 `加注`，不拼一个猜出来的金额。

跟注不写金额。本街投入仍由旁边的黄色筹码表示。

`post` 不产生标签。翻前第一次自愿加注因为前面已有盲注，显示 `加注到 $N`，与现有 `raiseVerb` 一致：只有翻后、本街还没有下注时才叫「下注」。

### 3.3 保留与清空

- 过牌、跟注、下注、加注留到这个人在本街再次行动。再次行动后只显示新的那一条。
- 换街后，当前街过滤不到上一街的过牌、跟注、下注、加注，这些标签消失。弃牌和全下看的是座位状态，继续显示。
- 进入摊牌同样视为离开下注街：河牌上的过牌、跟注、下注、加注消失；弃牌和全下仍在。
- `startHand` 重置状态和 `streetActions` 后，全部标签消失。
- 空闲、没有牌桌时不显示。

## 4. 音效

### 4.1 声音

用 Web Audio 合成，不新增音频文件。每种声音都短，全下最长也不超过 350 毫秒。固定较低音量，大约主增益 0.15。

| 时机 | 声音 |
| --- | --- |
| 过牌 | 轻敲一下 |
| 弃牌 | 低一声 |
| 跟注 | 一枚筹码 |
| 下注 | 两下筹码 |
| 加注 | 两下筹码，音高高于下注 |
| 全下 | 一枚筹码加一声短促低音 |
| 轮到你 | 单独一声提示，音色与上面都不同 |

下注和加注的区分与第 3.2 节相同。全下只要结果状态是 `all-in`，就用全下声，不用跟注或加注声。

本人和 NPC 的主动行动都响。`post` 不响。

轮到你：当前阶段是 `preflop`、`flop`、`turn` 或 `river`，当前行动者是本人，且本人状态是 `active`。同一手、同一次轮到你只响一次。身份是 `handNumber + currentPlayerIndex + streetActions.length`。重新渲染、Strict Mode 重挂载不重复响。

同一次状态更新里既有新行动、又轮到本人时，先播行动声，约 200 毫秒后再播「轮到你」。离开牌桌或这次轮转已失效时取消后者。本人自己刚行动导致轮转离开本人时，只播行动声。

### 4.2 开关

牌桌右上角、「站起离开」左侧放一个按钮，文案为 `音效开` 或 `音效关`。点击立刻切换并写入 `localStorage` 键 `dz-pk-sound`，值为 `on` 或 `off`。缺键或无法识别的值视为 `on`。读写失败时本次页面按开着处理，不弹错误。

静音后不再发声，标签照常显示。不把静音期间错过的声音补播出来。

### 4.3 浏览器限制

在进入牌桌的那次点击里创建并 `resume` `AudioContext`。被浏览器拒绝、上下文不可用或之后 `resume` 失败时静默跳过，不抛到界面，标签继续工作。

`document.hidden === true` 时不播放，也不排队等回到前台再播。

## 5. 数据流

```text
playerFold / playerCheck / playerCall / playerRaise
        │  写入 streetActions 和座位状态（现有 store，不在 store 里播声音）
        ▼
GameTable 渲染
        │  seatActionLabel(player, stage, streetActions) → 一行文字或空
        ▼
行动声：相对上一帧，本手 streetActions 新增的非 post 各播放一次
轮到你：行动者变为符合 4.1 的本人时播放一次
```

播放器可以替换成测试用的记录器。已播放的进度和「轮到你」身份按 `handNumber` 记在模块里，避免同一次行动响两遍，也避免新手牌把上一手再播一遍。`startHand` 换手或 `streetActions` 变短时只重置进度，不为已有的 `post` 发声。一次渲染里新增多条非 `post` 时按顺序各播一次。

延迟的「轮到你」在真正播放前再检查静音、页面是否隐藏，以及这次轮转是否仍有效。

不在回放历史、补记日志或单纯滚动流水时播放。

## 6. 测试

纯函数测试放在 `src/game/seatActionLabel.test.ts`：

- 过牌、跟注、翻后第一次下注、翻前后的加注、弃牌、全下各自得到第 3.2 节的文案。
- 跟注文案不含 `$`。
- 盲注 `post` 单独存在时没有标签。
- 同一人在本街先过牌再下注时，只剩下注。
- 换街后，上一街的过牌或加注消失；弃牌和全下仍在。
- 摊牌时河牌的过牌消失，弃牌仍在。
- `raise.to` 缺失或不是正的安全整数时，不出现假金额。

音效门控测试注入播放记录器，不依赖真实声卡：

- 过牌、弃牌、跟注、下注、加注、全下和「轮到你」命中第 4.1 节的声音种类。下注和加注不是同一种。
- `post`、静音、页面隐藏、重复的行动、重复的轮到你身份都不调用播放器。
- 新手牌重置进度后，不播放该手已有的盲注。
- 同一次更新里的行动声和「轮到你」都会记下，且提示音晚于行动声。延迟播放前若已静音、页面隐藏或轮转失效，不播放。

不新增 jsdom 或组件测试库。`GameTable.tsx` 不再包含英文状态文案 `Folded` 和 `ALL-IN`，用一次读取该文件的断言锁住。四个座位都调用 `seatActionLabel`。

## 7. 验收

一手牌里可以不看侧边栏完成这些判断：谁过牌、谁跟注、谁下注或加注到多少、谁弃牌、谁全下。换街后金额类标签消失，弃牌和全下还在。音效开关关闭后刷新页面仍然关闭，打开后刷新页面仍然打开。后台标签页没有声音。流水内容与改动前一致。
