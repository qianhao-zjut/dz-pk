## 开发约束

- 在现有 dz-pk 项目内推进，保持简单，遵循 `.cursor/rules/project-workflow.mdc`；不创建功能分支、worktree 或 PR。
- 本轮只实现本地 NPC v1：信息过滤、权益抽样、分街策略、三种风格、合法执行与验证。
- 不接大模型、不做联网多人或自我训练、不部署，不修改资金余额和数据库。
- 自主完成本地实现和验证。常规模块拆分、配置和测试选择无需重复请求批准；遇到会扩大范围的产品决定再说明。
- 开始前检查 Git 状态，保留用户已有改动；不删除文件，不回退未授权的改动。

## 阶段 A：接口与安全接入

- [ ] 重新读 `src/store/gameStore.ts`、`src/components/GameTable.tsx`、`src/utils/poker.ts`、`src/act/applyAction.ts` 与现有测试，确认规格仍适用。
- [ ] 定义 `AIObservation / LegalActions / AIAction / AIDecision / AIProfile`，金额和轮次语义与规格一致。
- [ ] 实现白名单 observation，复制自己的底牌和公开字段，不包含真实牌堆、对手底牌、原始日志。
- [ ] 为翻前保留足够的结构化公开行动概要，不通过含底牌日志获取。
- [ ] 增加 `decisionRevision / turnToken`，覆盖会使当前决策失效的牌局变动。
- [ ] 实现 NPC executor：先校验当前玩家、轮次、动作和金额，再调用现有动作方法。
- [ ] 用简单安全策略先打通 `actAI → observation → decide → executor`，保持人类操作和牌桌流程正常。
- [ ] 补信息隔离、合法动作、短码金额和过期 / 重复结果测试。

阶段出口：机器人已经走统一接口，且不透视、不执行非法或过期动作。此时尚未完成智能策略。

## 阶段 B：权益计算

- [ ] 实现仅由可见牌构建未知牌集合的 Monte Carlo 抽样，允许注入 RNG。
- [ ] 校验牌数、牌合法性与重复牌；仅对 active / all-in 对手抽样，异常输入有界失败并兜底。
- [ ] 联合抽取多人底牌、补全五张公共牌，复用牌型比较；平局按获胜人数分配。
- [ ] 提供均匀随机对手范围的假设说明、有效样本数与耗时诊断。
- [ ] 实现拟议跟注后的分池资格和预计回收参考，覆盖短筹码、弃牌贡献与超额返还。
- [ ] 测皇家同花顺平局、绝对坚果、牌唯一、不修改输入、多人权益与边池资格。
- [ ] 测真实隐藏牌 / deck 改变不影响固定种子的权益和决策。
- [ ] 运行 `100 / 500 / 2000` 次采样测量，记录浏览器、设备、对手数、耗时和实际完成样本数。

阶段出口：权益定义正确、边池不夸大可赢金额，且知道计算开销。不能用尚未验证的概率公式顶替抽样。

## 阶段 C：策略与个性

- [ ] 实现起手牌标准类别、短桌位置映射，以及未开池 / 面对加注 / 再加注的翻前范围表。
- [ ] 实现翻后继续价格、人数、牌面风险、有效筹码与权益参考规则。
- [ ] 明确少量价值下注、加注与条件诈唬的候选尺度，并正确换算为 `raiseTo`。
- [ ] 单独约束全下决策，避免“某牌型 / 某权益阈值就全下”。
- [ ] 配置 `ai_0` 稳健、`ai_1` 激进、`ai_2` 保守；个性与合法动作约束分离。
- [ ] 把解释信息留在本地调试结构，避免实时公开或云端日志暴露 NPC 底牌。
- [ ] 用固定场景和种子集合验证：弱牌面对高价格更少继续、强牌有价值下注、三个风格方向可区分。

阶段出口：动作会随手牌、街、价格、位置和个性改变，策略理由可复现。具体参数留在配置中并说明其启发式性质。

## 阶段 D：预算、运行与回归

- [ ] 按测量结果选默认样本数与预算；实测超过 50ms 的主线程重计算采用 Worker 或可让出的分批执行。
- [ ] runtime 实现同令牌 in-flight 去重，错误 / 超时恢复和旧结果丢弃；异步路径覆盖取消与整体超时。
- [ ] 保留 1.5 秒展示节奏，检查多人连续行动、同一街再次行动、全下摊牌、新手和离桌。
- [ ] 跑现有与新增单元测试、生产构建及 lint；如果有既存问题，记录基线并区分本次新增问题，不顺手扩大修复范围。
- [ ] 本地浏览器试玩多手，确认按钮 / 动画响应、筹码和底池正常、日志继续同步。
- [ ] 更新本文状态、规格中的实现差异、性能和已知限制，提供可以直接复核的交付说明。

阶段出口：所有核心验收完成，功能可在本地直接使用。策略强度仅报告已测证据，不凭少数胜局下结论。
